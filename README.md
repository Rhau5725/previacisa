# Clínica Cisa — prévia do site

Página estática responsiva em HTML, CSS e JavaScript, sem dependências de build.

## Visualização

Abra `index.html` ou sirva a pasta raiz com um servidor HTTP estático.

## Vercel

Importe este repositório como projeto estático (framework Other), com a raiz como diretório de saída. A configuração está em `vercel.json`.
